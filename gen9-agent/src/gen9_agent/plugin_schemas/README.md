# Agent Plugins schemas

The official JSON Schemas of the [Agent Plugins Specification](https://agent-plugins.org/specification),
copied unchanged from `github.com/agentplugins/agent-plugins-spec` (`schemas/`, commit `d92e6f4`,
Apache-2.0). The spec forbids fetching a schema while loading a plugin, so the loader (`plugins.py`)
reads these. A new spec version adds its folder here.
